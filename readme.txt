Make a WordPress environment visibly distinct from production.

Requires WordPress 6.4 or later and PHP 7.4 or later.

== Description ==

Development Mode Indicator gives developers a small, focused settings screen for identifying development, staging, testing, QA, maintenance, or custom environments.

Choose an Admin Bar indicator, a fixed watermark, or a striped bottom border. The React settings screen includes a live preview and display-specific controls. Indicators can run on the frontend and in WordPress admin screens, and disabling the indicator does not remove saved settings.

== Installation ==

1. Upload the `development-mode-indicator` folder to `wp-content/plugins/` or upload a ZIP in Plugins > Add New > Upload Plugin.
2. Activate Development Mode Indicator.
3. Open Settings > Development Mode.
4. Configure the environment and save.

== Privacy ==

This plugin does not collect or transmit personal data. Settings are stored in the site's WordPress options table and are only editable by users with the `manage_options` capability.
